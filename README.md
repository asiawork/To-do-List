# แปะไว้ก่อน

กระดานโน้ตแปะงานสำหรับจอคอม หนึ่งงานต่อหนึ่งแผ่น มีน้องโน้ตคอยเชียร์อยู่มุมจอ

## ใช้งาน

- **สร้างโน้ต**: กดสีโน้ตบนแถบด้านบน, ดับเบิลคลิกที่ว่างบนกระดาน หรือกด `N`
- **แก้ข้อความ**: คลิกที่โน้ต แล้วกด `Enter` เพื่อจบ (`Shift+Enter` = ขึ้นบรรทัดใหม่)
- **ย้ายโน้ต**: ลากได้เลย
- **เลื่อนกระดาน**: ลากที่ว่าง หรือเลื่อนลูกกลิ้ง/ทัชแพด
- **ซูม**: `Ctrl/⌘ + ลูกกลิ้ง`, `Ctrl/⌘ + 0` = ดูทั้งกระดาน
- **โซน**: กระดานแบ่งเป็น Routine, Project, Meeting, Adhoc ลากหัวโซนเพื่อย้ายทั้งโซนพร้อมโน้ตข้างใน คลิกชื่อเพื่อเปลี่ยนชื่อ ลากมุมขวาล่างเพื่อปรับขนาด เพิ่มโซนได้จากเมนู `⋯`
- **งานประจำ**: โน้ตในโซน Routine ตั้งรอบได้ (ทุกวัน, ทุกสัปดาห์, ทุกเดือน) ติ๊กเสร็จแล้วพอขึ้นรอบใหม่จะกลับมาเป็นงานที่ยังไม่ทำเอง และไม่โดนเก็บกวาด
- **แต่งตัวน้องโน้ต**: เมนู `⋯` → แต่งตัวน้องโน้ต ปรับทรงผม (ยาว บ็อบ มัดจุก สั้น) สีผม สีผิว สีเสื้อ สีโน้ตบนหัว แว่น แก้ม หรือซ่อนน้องโน้ต
- **ย้อนการลบ**: `Ctrl/⌘ + Z`

ข้อมูลเก็บไว้ในเบราว์เซอร์ของเครื่องนั้น (localStorage) สำรองหรือย้ายเครื่องได้จากเมนู `⋯` → สำรองกระดานเป็นไฟล์

## ติดตั้งลงเครื่อง

เปิดผ่าน GitHub Pages ด้วย Chrome หรือ Edge แล้วเลือก "ติดตั้งลงเครื่อง" ในเมนู `⋯` (หรือไอคอนติดตั้งบนแถบ URL) จะได้แอปแยกหน้าต่างที่ใช้ได้แม้ออฟไลน์

ดาวน์โหลด repo เป็น zip แล้วเปิด `index.html` ตรง ๆ ก็ใช้ได้เหมือนกัน

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` `style.css` `app.js` | ตัวแอป |
| `character.js` | น้องโน้ต (SVG วาดด้วยโค้ด 7 ท่า: idle, wave, write, cheer, carry, sleep, tea) |
| `fonts/` | ฟอนต์ไทย Mali, Sriracha, Itim, Kodchasan (SIL Open Font License) ฝังไว้ให้ใช้ออฟไลน์ ใบอนุญาตอยู่ใน `fonts/OFL.txt` |
| `sw.js` `manifest.webmanifest` `icons/` | ทำให้ติดตั้งเป็นแอปและใช้ออฟไลน์ได้ |
